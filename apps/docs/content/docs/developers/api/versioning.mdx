## Overview

Hanzo Sign serves two public APIs, each at its own base URL, and neither carries a version segment:

- **Operation API** — `https://esign.hanzo.ai/v1/rpc`. Every operation the app performs, one `POST` per operation. Its spec is at `/v1/rpc/openapi.json`.
- **Resource API** — `https://esign.hanzo.ai/v1/rest`. Documents and templates as resources. Its spec is at `/v1/rest/openapi.json`.

<Callout type="info">New integrations should use the operation API.</Callout>

Changes are additive. When a feature or endpoint is deprecated, the release notes say so and give a timeline for its removal.
